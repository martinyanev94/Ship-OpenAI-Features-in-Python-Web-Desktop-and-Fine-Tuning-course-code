# Course projects

This OpenAI Python tutorial teaches you to build and ship practical AI applications across web, desktop, and fine-tuning workflows. Create runnable products that connect Chat Completions, DALL-E, Whisper, Stripe, Azure, Django, Flask, Tkinter, PyQt, and PowerPoint automation. You will learn how to: • Authenticate securely and verify Chat Completion

This repository contains the runnable project code built throughout the course.
Each lesson evolves these files; the repository stores the final working state
instead of disconnected per-lesson snippets.

## Projects and run commands

### `chat-model-selection-lab`

```bash
cd chat-model-selection-lab
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

## Suggested workflow

1. Clone the repository.
2. Enter the project directory shown above.
3. Install dependencies with the listed command.
4. Run the app or script, then run its tests where provided.
5. Complete the final project in `FINAL_PROJECT.md`.
